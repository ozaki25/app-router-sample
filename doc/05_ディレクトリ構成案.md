# ディレクトリ構成案

```
src/
  app/
    layout.tsx         # 共通レイアウト
    page.tsx           # トップページ
    blogs/
      page.tsx         # ブログ一覧・投稿
    images/
      page.tsx         # 画像一覧・アップロード
    likes/
      page.tsx         # Like一覧
    tags/
      page.tsx         # タグ一覧
    login/
      page.tsx         # ログイン（モック）
    components/
      Header.tsx       # ヘッダー
      ...              # その他共通コンポーネント
    context/
      AuthContext.tsx  # 認証状態管理
    api/
      blogs/route.ts   # ブログAPI
      images/route.ts  # 画像API
      likes/route.ts   # LikeAPI
      tags/route.ts    # タグAPI
```

- 必要に応じてtypes/やutils/も追加
- データ・認証は全てモックで実装
