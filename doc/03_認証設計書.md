# 認証設計書（モック）

## 1. 認証方式

- 完全モック（本番認証は未実装）
- ログイン状態はuseState/useContextで管理
- ユーザー名入力のみでログイン可能
- ログアウトで状態リセット

## 2. 実装イメージ

- AuthContextでグローバルに認証状態を管理
- ログイン時は仮ユーザーオブジェクト（例: { id: 1, name: 'mockuser' }）をセット
- ログアウト時はnullに
- ページガードは`if (!user) return <LoginPage />`で分岐

## 3. 注意事項

- 本番認証導入時はAuthContextの実装を差し替え
- API Routeも認証チェックはスキップ
