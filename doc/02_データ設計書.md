# データ設計書（仮DB）

## 1. ユーザー

- id: number
- name: string

## 2. ブログ

- id: number
- title: string
- body: string
- authorId: number
- createdAt: string

## 3. 画像

- id: number
- url: string
- uploaderId: number
- createdAt: string

## 4. Like

- id: number
- userId: number
- blogId: number

## 5. タグ

- id: number
- name: string

## 6. タグ付与

- id: number
- tagId: number
- blogId: number

---

- 各データはuseState/useReducerやAPI Routeのメモリ上で管理
- idはインクリメントで仮生成
- createdAtはISO文字列
- 本番DB移行時は型定義を流用可能
